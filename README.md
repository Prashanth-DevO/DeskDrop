# AvaloniaFileTransfer (Work in Progress)

A cross-platform desktop file transfer utility built with C# and the Avalonia framework. 

## About This Project
I'm building this project to learn modern cross-platform desktop development with Avalonia and .NET. The goal is to design a clean, responsive app that can handle file transfers between desktop systems while mastering MVVM architecture, asynchronous programming, and cross-platform UI design.
